# samholtzen.github.io

Source for Sam Holtzen's academic website, built with [Astro](https://astro.build) and deployed to GitHub Pages.

```sh
npm install      # once
npm run dev      # preview at http://localhost:4321
npm run build    # production build into dist/
```

Pushing to `main` deploys the site. See [AGENTS.md](AGENTS.md) for where content lives and how to update it.
